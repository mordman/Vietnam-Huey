# Changelog

## [0.1.0] - 2024-XX-XX

### Добавлено
- **Этап 0: Инициализация проекта**
  - Базовая структура проекта (Vite + ES modules)
  - Настройка vite.config.js с WASM плагинами
  - Конфигурация с feature-флагами (config.js)
  - Структура папок для всех модулей

- **Этап 1: Физическое ядро + игровой цикл**
  - Time.js — система времени с фиксированным timestep (60 Гц) и интерполяцией
  - PhysicsWorld.js — обёртка над Rapier3D с синхронизацией Three.js мешей
  - DebugRenderer.js — визуализация коллайдеров (F3)
  - main.js — точка входа, игровой цикл
  - Тестовая сцена: падающий куб на плоскость

### Технические детали
- Интеграция Rapier3D WASM
- Accumulator-based fixed timestep
- Интерполяция между шагами физики
- FPS counter в HUD
- Обработка изменения размера окна

### Известные проблемы
- Отсутствуют (базовый функционал работает)
