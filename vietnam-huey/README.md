# Vietnam Huey 🚁

Браузерная 3D-игра на JavaScript (Three.js + Rapier3D) — аркадный симулятор боевого вертолёта **Bell UH-1 Iroquois** («Huey») времён Вьетнамской войны.

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| W / S | Тангаж (нос вверх/вниз) |
| A / D | Крен (наклон влево/вправо) |
| Q / E | Рыскание (поворот носа) |
| Shift | Тяга вверх |
| Ctrl | Тяга вниз |
| 1 / 2 / 3 | Смена позиции (пилот/пулемётчик/TPP) |
| ЛКМ | Огонь M60 |
| ПКМ | Прицеливание |
| H / L / R | Команды ИИ-пилоту |
| F3 | Отладочный режим (коллайдеры) |

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр сборки
npm run preview
```

## 📋 Технологический стек

- **Рендеринг:** Three.js r160+
- **Физика:** Rapier3D (WASM)
- **Сборка:** Vite
- **Шум:** simplex-noise
- **Звук:** Howler.js
